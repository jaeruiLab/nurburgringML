Nordschleife Learners

100 AI cars learn the 20.8 km Nürburgring Nordschleife two different ways: GA a genetic algorithm that breeds the best drivers, and PPO reinforcement learning that trains one shared driver. Every car below is a recorded replay of a saved checkpoint, driven from the start line.

How it works

GA Survival of the fittest drivers

Each of the 100 cars has its own small brain: a neural network that turns what the car "sees" (nine distance sensors, its speed, its angle to the road and the upcoming bends) into steering and throttle.

A generation starts with everyone on the grid and lasts until the last car crashes. Cars that got further score higher. The 5 best brains are kept as they are; the other 95 are their "children": two good parents' numbers mixed together, plus a few small random changes.

Nobody tells a car how to drive. Good brains simply have more children, so each generation drives a little better. You see whole generations here, and each one is a different set of 100 drivers.

PPO One driver, learning from every moment

PPO trains one brain that drives all 100 cars at once. Every 1/60 of a second each car gets a small reward for the meters it gained and a penalty when it crashes.

While learning, the driver adds a little randomness to its actions to try new things. After every few seconds of driving it asks, for each moment: did that action turn out better or worse than expected? It then nudges itself toward the better actions, but never too far at once (that is the "proximal" in PPO).

In these replays all 100 cars use the same brain. They differ only by that exploration randomness, which is why they spread out. The stats also show how far the brain gets with the randomness switched off.

What's a fair comparison?

A GA "generation" and a PPO "update" are completely different amounts of work, so the slider pairs each GA generation with the PPO checkpoint that had driven about the same number of environment steps, which counts how much driving experience each method had used.

Training used random start points for PPO and the start line for the GA; here both always start from the line, so you see what each driver can do in the same situation.

Run it yourself

The simulation and both learning methods are written in Python with PyTorch: every car is simulated in one batched tensor operation, with no loop over cars.

pip install -r requirements.txt
python main.py                 # watch the GA learn live (pygame)
python main.py --algo ppo      # the same for PPO
python compare.py              # the fair GA-vs-PPO experiment
python record.py               # re-record the replays on this page
